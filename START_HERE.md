# Start Here — LearnHub Assignment Pack

This folder contains the LearnHub frontend and backend, the feature proposal, report template, setup/testing guide, and final checklist.

## Three added features
1. Course discussion attached to a course.
2. Private student study notes with create, edit, and delete.
3. Database-backed saved courses.

## First things to do
1. Read `FEATURE_PROPOSAL.md`.
2. Read `QUICK_START_AND_TESTS.md` and configure local `.env` files from each project's `.env.example`.
3. Create/seed a local learning database following the backend README.
4. Apply `learnhub-backend-main/database/feature_migration.sql`.
5. Start backend and frontend in separate terminals.
6. Complete actual tests and replace placeholders in `REPORT_TEMPLATE.md`.
7. Fork and push the two projects to your own GitHub account; this pack does not contain Git history, so commit IDs must be captured from your forks.

## Important honesty note
Backend JavaScript files passed Node's syntax check. A frontend production build and live API/database test could not be confirmed in this environment because dependency installation did not finish. Run the setup and testing steps on your computer and record the real results before submitting.
